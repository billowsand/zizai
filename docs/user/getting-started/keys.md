## 切换模式

| 操作 | 按键 |
|---|---|
| 中 / 英切换 | 单击 `Shift`；或点击任务栏 / 悬浮状态条上的「中 / A」 |
| 直接输入大写英文 | `Caps Lock` 亮起（中英模式均可） |
| 输入拼音时临时输入一个大写字母 | `Shift + 字母`：拼音原样上屏，再输入该大写字母；[辅码](../input/shuangpin.md) 开着时改作辅码键（见辅码一节） |
| 切换全角 / 半角标点 | 点击悬浮状态条上的「，。」格，中英各记一份 |
| 切换到其他输入法 | `Win + Space`（系统） |

主键盘数字和常用标点按当前系统键盘布局识别；非美式布局的字母、AltGr 和组合音符输入仍有局限。

## 输入组句时

| 操作 | 按键 |
|---|---|
| 上屏高亮候选（无候选时上屏所敲的拼音） | `Space` |
| 上屏当前页第 N 个 | `1` 至 `9` |
| 将拼音字母原样上屏 | `Enter` |
| 删除光标前一个字母 | `Backspace` |
| 清空 | `Esc` |
| 移动高亮（到页边自动翻页） | `↑` / `↓` |
| 翻页 | `[` `]`、`PageUp` / `PageDown` |
| 移动拼音光标 | `←` / `→` |
| 光标移到开头 / 末尾 | `Home` / `End` |

光标停在中间时，候选只按光标之前的拼音计算（`ni|hao` 出 你）；上屏后其余拼音保留，光标移到末尾。
若前面某个音节输入有误，可按 `←` 移回去、`Backspace` 删除后重输、`End` 回到末尾。

翻页键对可改为 `,` `.` 或 `-` `=`：「设置 → 通用 → 按键」。

## 英文模式下

所敲字母直接进入输入框，不出候选窗口：`Space`、`Enter`、`Tab`、方向键、数字键与标点都是它们本来的意思，与未使用输入法时一致。
字母缺省小写，按住 `Shift` 输出大写。

## 删除候选

`Shift + 数字` 删除第 N 个候选。仅在输入拼音时有效：用户自造的词整个删除；
词库中的词不删除，但清除对它的全部学习记录，恢复原始排序。删除后拼音行下方短暂显示结果，输入下一个键即消失。

修饰键可在「设置 → 快捷键」里改；`Alt + 数字` 会被应用作为菜单快捷键截获，缺省用 `Shift`。

## 语音输入

开启本地语音输入后，按一下右 `Alt` 开始录音，再按一下后识别并上屏。快捷键可改为右 `Ctrl`、`Caps Lock` 或 `Scroll Lock`。
按住它再敲别的键（当组合键用）时不会开始录音，松手也不会。密码框不会拦截该键。
准备模型与使用说明见[语音输入](../input/voice-input.md)。
