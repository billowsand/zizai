语音识别在本机完成，不使用剪贴板，也不会上传录音。可选的大模型语句整理会把识别文字发送到你配置的服务；关闭整理时文字也不离开本机。此功能目前仅支持 Windows，且需要单独准备 SenseVoice 模型。

## 开启

1. 准备 SenseVoice 的 `model.int8.onnx` 与 `tokens.txt`。
2. 在安装目录中建立 `data\voice\sense-voice`，把两个文件放入该目录。
3. 打开「设置 → 语音输入」，开启「本地语音输入」。
4. 在「语音快捷键」中选择听写开关键。缺省为右 `Alt`。
5. 在「语音麦克风」中选择“系统默认”或一个指定输入设备；指定设备断开时不会悄悄改用其他麦克风。
6. 若希望少按一次键，可开启「停顿后自动完成」；检测到你说完并安静约 1.2 秒后会自动识别。
7. SenseVoice 已原生输出标点和规范化数字，无需再下载标点模型。
8. 若已运行 LM Studio 等 OpenAI 兼容服务，可开启「语句整理」，填写服务地址与模型名称。

若模型放在其他位置，可在「设置 → 高级 → 配置文件」中修改语音模型路径。保存后一秒内生效。

## 使用

把光标放入普通文本框，按一下语音快捷键后说话。原来的候选窗口会在同一位置切成语音面板：上方是实时波形、当前阶段与录音时长，下方是临时转写；若一直没有收到有效声音，会提示靠近麦克风。再次按快捷键后它原地进入“正在识别”，最终文字直接写入开始录音时的文本框。

开启「停顿后自动完成」时，说完后保持安静即可；仍然可以再按一次快捷键立即结束。功能会先确认收到了一小段连续语音，敲键、碰麦克风等瞬时声音不会直接结束录音。

临时转写只用于反馈“听到了什么”，结束录音后的完整识别仍会重新处理整段录音，因此最终文字可能与临时结果略有不同。

- 录音期间继续键入、切换窗口或切换输入法，会取消这次听写。
- 按住语音快捷键再敲别的键（把右 `Alt` 当组合键用）不会开始录音。
- 录音、识别与整理期间按 `Esc` 都会立即取消；识别超时或 Worker 异常后可直接再次按快捷键重试。
- 极少数情况下文字写不进输入框（应用一直不受理写入），十秒后会放弃并提示重试，快捷键随即恢复。
- 密码框不会拦截语音快捷键，也不会启动麦克风。
- 没有听清时不会写入文字。
- 模型、麦克风或语音组件不可用时，普通键盘输入不受影响。

「语句整理」只处理最终文字，录音期间的临时转写保持原样。大模型只能提出整理结果：如果服务未启动、请求超时、增删了正文或改动过大，
输入法会自动放弃它的结果并使用 SenseVoice 原文。转写保持本机离线；整理文字会发送到你配置的服务，是否离线取决于该服务。
