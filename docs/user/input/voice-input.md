语音输入在本机完成，不使用剪贴板，也不会把录音或识别文字上传到网络。此功能目前仅支持 Windows，且需要单独准备 SenseVoice 模型。

## 开启

1. 准备 SenseVoice 的 `model.int8.onnx` 与 `tokens.txt`。
2. 在安装目录中建立 `data\voice\sense-voice`，把两个文件放入该目录。
3. 打开「设置 → 通用」，开启「本地语音输入」。
4. 在「语音快捷键」中选择听写开关键。缺省为右 `Alt`。

若模型放在其他位置，可在「设置 → 高级 → 配置文件」中修改语音模型路径。保存后一秒内生效。

## 使用

把光标放入普通文本框，按一下语音快捷键后说话。原来的候选窗口会在同一位置切成语音面板：上方是实时波形与当前阶段，下方是临时转写；再次按快捷键后它原地进入“正在识别”，最终文字直接写入开始录音时的文本框。

临时转写只用于反馈“听到了什么”，结束录音后的完整识别仍会重新处理整段录音，因此最终文字可能与临时结果略有不同。

- 录音期间继续键入、切换窗口或切换输入法，会取消这次听写。
- 录音期间按 `Esc` 会立即取消；识别超时或 Worker 异常后可直接再次按快捷键重试。
- 密码框不会拦截语音快捷键，也不会启动麦克风。
- 没有听清时不会写入文字。
- 模型、麦克风或语音组件不可用时，普通键盘输入不受影响。

当前版本不提供自动润色；识别与临时转写均在本机完成。
