开始菜单的「字在设置」，或悬浮状态条上的 ⚙，打开设置。

常规设置修改即时生效。

设置分五页。左侧选择页面，右侧用紧凑列表显示设置项；窗口标题栏也使用当前配色。

| 页 | 分组 | 内容 |
|---|---|---|
| 通用 | 输入方案 | 双拼方案、辅码开关（小鹤，需先开双拼） |
| 通用 | 按键 | 翻页键对、删除候选的修饰键、语音输入与语音开关键（固定键全表见 [按键与快捷键](../getting-started/keys.md)） |
| 通用 | 标点 | 中文模式、英文模式的标点转全角开关 |
| 通用 | 候选质量 | 本地整句模型开关（见 [本地整句模型](../input/local-model.md)）、「输入拼音时中文候选排在英文词前面」、学习输入习惯开关 |
| 候选窗口 | | 配色（奶油 / 字在蓝 / 紫藤拿铁 / 森林，每张选择卡同时展示浅色与深色）、每页候选数 1 至 9、字体（从系统字体下拉列表里选，「系统字体」是默认；没装的字体自动回到系统字体）、拼音显示位置（行内 + 窗口 / 只在行内 / 只在窗口）、悬浮状态条开关 |
| 词库 | | 随包领域词库开关，导入 / 开关 / 移除用户词库，见 [词库](dictionaries.md) |
| 高级 | 文件与目录 | 在记事本中打开配置文件、打开数据目录、打开日志目录、打包日志到桌面 |
| 高级 | 日志与诊断 | 详细日志、记录输入日志、清空输入日志 |
| 关于 | | 版本与构建号、官网与 GitHub 链接、输入统计（见 [统计](../input/statistics.md)）、许可证与随包数据来源、隐私与反馈说明 |

设置程序、主题卡中的示例文字、候选窗口与悬浮状态条共用「字体」设置；选择「系统字体」时，它们采用同一套默认字体与中文回退字体。图标使用独立图标字族，不会随候选字体改变形状。

四套配色都包含浅色与深色，明暗始终跟随 Windows，设置中不再单独切换。换配色后，设置窗口、候选窗口和悬浮状态条会同步更新。

## 候选窗口与拼音位置

候选固定排成一行，页码在行尾。
「只在窗口」显示拼音适用于终端与部分 Electron 应用，这类应用对行内拼音的渲染效果较差。

## 自定义短语

设置页里没有这一项，直接在配置文件里写 `[[custom_phrases]]`，「高级」页有「在记事本中打开」，
文件内每一项均附说明。文本可以包含空格、换行、地址、长回复或标点，按原样输出；候选窗口只展示长文本的简短预览。

例如将 `ee` 的第 1 位设置为 `：`，第 2 位设置为 `；`，输入 `ee` 后按空格选择首项，按 2 选择第二项。
普通拼音候选填入其他位置，学习与模型重排不会改变自定义位置。
同一个输入码的位置不能重复，写重了整份配置不生效（设置页会说明错误）。英文模式不触发自定义短语。

## 直接修改配置文件

全部设置保存在一个配置文件中，「高级」页有「在记事本中打开」，文件内每一项均附说明。保存后一秒内生效，无需重新切换输入法。
